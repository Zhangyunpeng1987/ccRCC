# Single-cell multi-omics analysis and prognostic modeling in ccRCC

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![R](https://img.shields.io/badge/Language-R-blue.svg)](https://www.r-project.org/)

This repository contains the R scripts used for the single-cell RNA-seq, single-cell ATAC-seq, regulatory-network, cell-cell communication, and prognostic-modeling analyses described in the revised manuscript.

The code is provided to improve transparency and reproducibility of the computational workflow. Large raw data files and intermediate R objects are not stored in this repository and should be downloaded or regenerated as described below.

## Data sources

- scRNA-seq and scATAC-seq data: GEO accession `GSE207493`.
- TCGA-KIRC expression and clinical data: Genomic Data Commons / TCGA.
- External prognostic evaluation cohort: `E-MTAB-1980`.

The single-cell dataset contains 19 paired ccRCC scRNA-seq and scATAC-seq samples. Sample-level metadata are provided in the revised Supplementary Table S1.

## Script overview

### `Code_summary/CODE-RNA_cleaned.R`

This script contains the scRNA-seq and downstream transcriptome-based analyses:

- Loading and preprocessing 19 scRNA-seq samples.
- Cell-level quality control and Seurat object construction.
- Sample-level Harmony correction using `orig.ident`.
- Major cell-type annotation and T cell, myeloid-cell, and macrophage subclustering.
- inferCNV-based malignant epithelial-cell identification.
- Monocle3 trajectory analyses.
- Differential expression, functional enrichment, and regulatory-network preparation.
- MultiNicheNet cell-cell communication analysis.
- TCGA-KIRC and E-MTAB-1980 data preparation.
- Machine-learning prognostic modeling with the `Mime1` workflow.

### `Code_summary/CODE-ATAC_cleaned.R`

This script contains the scATAC-seq and chromatin-accessibility analyses:

- Loading per-sample peak, metadata, and fragment files.
- Signac-based scATAC-seq quality control.
- TF-IDF, SVD/LSI, and sample-level Harmony correction using `dataset`.
- Gene activity calculation and label transfer from scRNA-seq annotations.
- High-confidence scATAC cell filtering using prediction score >= 0.5.
- T cell, myeloid-cell, macrophage, and WHO-grade subset analyses.
- Monocle3 trajectory analyses on scATAC-seq-derived objects.
- TF motif enrichment, Cicero/cCRE analysis, peak-gene linkage, and regulatory-network preparation.

```text

`-- E-MTAB-1980/

```

The original scripts were run in a local Windows environment and therefore contain absolute paths such as `D:/`, `E:/`, and `F:/`. These paths are marked with `TODO: Change to relative path for reproducibility` comments and should be replaced with local paths before rerunning.

For rerun preparation, copy `paths_template.R` to `paths.R` and edit the paths for the local data and output directories. The helper script `check_required_files_template.R` can then be run from the `code/` directory to check whether the expected input folders and key files are present. This input check does not run the analysis or modify any results.

## Recommended running order

1. Run `CODE-RNA_cleaned.R` through Result 1 to generate the processed scRNA-seq object and cell-type annotations.
2. Run `CODE-ATAC_cleaned.R` through Result 1 to generate the processed scATAC-seq object, gene activity matrix, and label-transfer annotations.
3. Run tumor-cell trajectory and network sections in both scripts.
4. Run CD8+ T-cell trajectory and network sections in both scripts.
5. Run myeloid-cell/macrophage trajectory and network sections in both scripts.
6. Run MultiNicheNet analysis in `CODE-RNA_cleaned.R`.
7. Run the machine-learning and survival-analysis section in `CODE-RNA_cleaned.R`.

Some later sections depend on intermediate files generated by earlier sections, including `.Rdata`, `.rds`, `.csv`, and `.xlsx` files. If these objects are not present, rerun the corresponding upstream section first.

Before rerunning the workflow in a new environment, users may run the optional input check:

```r
setwd("path/to/code")
source("check_required_files_template.R")
```

This creates `input_check_report.csv`, which lists expected input paths as `FOUND` or `MISSING`.

## Key reproducibility notes

- The scRNA-seq workflow uses Harmony with `orig.ident`, representing sample identity.
- The scATAC-seq workflow uses Harmony with `dataset`, representing sample identity.
- Epithelial and malignant epithelial-cell analyses in both modalities extract epithelial cells from globally Harmony-corrected objects; no additional epithelial-cell-specific Harmony correction is performed before malignant epithelial-cell extraction.
- In the current code, `Tcellatac` uses `dataset` for Harmony correction, and the WHO3 scATAC subset uses Harmony embeddings for UMAP and nearest-neighbor construction.
- TCGA-KIRC is split into a training set and internal validation set at an approximately 7:3 ratio; the implemented training set contains 354 patients.
- E-MTAB-1980 is used as an external evaluation cohort and is not used as the model-training input.
- Large computations were originally executed in modular sections rather than as one uninterrupted script. Users should run and inspect each section sequentially.

## Main R package dependencies

The scripts use the following major R packages:

- Single-cell analysis: `Seurat`, `SeuratWrappers`, `SingleCellExperiment`, `Signac`, `presto`, `clustree`.
- scATAC-seq and genomics: `BSgenome.Hsapiens.UCSC.hg19`, `BSgenome.Hsapiens.UCSC.hg38`, `TxDb.Hsapiens.UCSC.hg19.knownGene`, `chromVAR`, `chromVARmotifs`, `cicero`, `ChIPseeker`, `JASPAR2020`, `TFBSTools`.
- Trajectory and enrichment: `monocle3`, `ClusterGVis`, `rGREAT`, `org.Hs.eg.db`.
- Cell-cell communication: `multinichenetr`, `nichenetr`.
- Prognostic modeling and survival analysis: `Mime1`, `survival`.
- Data handling and plotting: `data.table`, `dplyr`, `tidyverse`, `ggplot2`, `ggpubr`, `patchwork`, `openxlsx`, `ComplexHeatmap`, `circlize`, `viridis`.

Current environment records are provided as `sessionInfo_current.txt` and `loaded_package_versions_current.csv`. These files document the local R session and loaded package versions used during code review and rerun preparation. They are not a locked computational environment file. Users are encouraged to record `sessionInfo()` again after rerunning the workflow in their own environment.

## Outputs

The workflow produces processed single-cell objects, trajectory objects, marker tables, enrichment tables, regulatory-network tables, machine-learning results, and figures used in the manuscript. Output file names and directories are specified in the corresponding script sections.

## Known limitations of the released code

- The scripts still contain local absolute paths from the original analysis environment and require path replacement before reuse.
- Intermediate files are written and loaded across sections; therefore, the full workflow is not currently packaged as a single command-line pipeline.
- Package installation commands and a locked computational environment file such as `renv.lock` are not currently included.
- Some figures require manually selected plotting dimensions or previously generated intermediate network files.

These limitations do not change the analytical steps reported in the manuscript, but they should be considered when rerunning the workflow in a new environment.
